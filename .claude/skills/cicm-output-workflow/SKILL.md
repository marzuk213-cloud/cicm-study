# CICM output workflow — entry point

1. Read `docs/CURRENT_WORKFLOW.md` (the eight routes) and refresh live Notion COMMAND
   (https://app.notion.com/p/39a6cdbdfe3d81fbb2dbfeecbd6b5797). COMMAND wins on conflict.
2. Refresh the position you need from its live owner (NEXT UP, Runthrough owner, Attempt
   Log, SMARK administration, Running Recall Log, Repair Boards) — never a dated snapshot.
3. Pick the route:
   - attempt to mark → route 1 (Yearly) or 2 (SMARK) via `saq-marker`, blind first
   - repair → route 3: full feedback first, count points, one chunk at a time, **end with
     the snappy complete model answer covering the whole stem**
   - Runthrough / `/smark` → route 2, independent progress
   - short question → route 4: Maz's Notion templates/rundowns first, short, linked
   - recall → route 5: shared history first, one question at a time
   - board build → `marzuk213-cloud/repair-board-builder`; visual build → `marzuk213-cloud/cicm-exam-visuals`
4. Check live Sydney time before any time claim. Write records only on real study events,
   refresh before writing, read back. Never invent XP, attempts, scores or completion.

Do not invoke the retired skills listed in `CLAUDE.md` unless Maz names one explicitly.
