## The mainstay in one screen

1. **Yearly** — exact-sitting SAQ write (15 min) → blind marking → full feedback → chunk repair → snappy whole-answer model → explicit done + verified records.
2. **Syllabus Runthrough + SMARK** — V5 notes/templates/model answers; independent progress.
3. **Chunk repair** — full feedback first, one point per chunk, **finish with the complete exam-writable model answer**. Works at home, walking or gym.
4. **Everyday questions** — "vanc?" pulls Maz's own Notion templates first, short answer, linked sources.
5. **Mixed casual recall** — one source-backed question at a time, shared history, dedupe by fact.
6. **Visuals** — Notion-first; new work → [`cicm-exam-visuals`](https://github.com/marzuk213-cloud/cicm-exam-visuals).
7. **Repair production** — daily board HTML → [`repair-board-builder`](https://github.com/marzuk213-cloud/repair-board-builder).
8. **Shared coordination** — existing owners and receipts, refresh before writes, no invented credit.

Authority: Maz's latest explicit instruction → live Notion owners → this repo (COMMAND
overrides stale repo text, never Maz).
